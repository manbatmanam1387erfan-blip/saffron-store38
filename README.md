# 🌸 Saffron Premium Online Shop

A modern, pastel‑styled single‑page web application for selling saffron online.  
This project demonstrates a clean UI, animated elements, tabbed navigation, and a hidden admin panel for editing content.

---

## ✨ Features

- **Pastel & Modern Design**: Soft color palette with smooth animations.
- **Tabbed Navigation**: Separate panels for packaged saffron, bulk saffron, extras, blog, and about.
- **Product Grid**: Responsive cards with title, price, and add‑to‑cart buttons.
- **Mini Cart**: Floating cart showing item count and total.
- **Hidden Admin Panel**:
  - Activated with `Ctrl + Shift + A`
  - Password: `zarmehr.iran.saffron`
  - Edit site title
  - Add new products dynamically

---

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Explore the shop interface:
   - Switch tabs to view different product categories.
   - Add items to the cart.
   - View blog posts and about section.

---

## 🔐 Admin Panel

- Press **Ctrl + Shift + A** to open the login prompt.
- Enter the password: `zarmehr.iran.saffron`.
- The admin panel allows:
  - Changing the site title.
  - Adding new products to the packaged saffron category.

> ⚠️ Note: This admin panel is **front‑end only**. It does not persist changes to a database or server. For production use, implement secure server‑side authentication and storage.
